# 35 Poems of John Muconto

> A digital poetry collection — a journey through life, told in thirty-five poems across five movements: **Formation**, **Struggle**, **Release**, **Observation**, and **Resolution**.

This repository contains the source code for the web edition of *35 Poems*, a collection written by **John Muconto** — a programmer and writer from Mozambique whose work sits at the intersection of analytical systems thinking and reflective spiritual inquiry.

---

## ✨ Features

- 📖 **Book-like reading experience** — a warm, paper-inspired layout with a cover, foreword, table of contents, and five thematic parts.
- 🌙 **Dark mode toggle** — pure CSS, no JavaScript required, with smooth transitions between light and dark themes.
- 📚 **Sticky index sidebar** — a scrollable table of contents that stays with you on desktop and slides in as a drawer on mobile.
- 🎯 **Scroll-spy highlighting** — the sidebar automatically highlights the poem you're currently reading (JavaScript-enhanced, gracefully degrades without it).
- 📱 **Fully responsive** — designed mobile-first, adapting cleanly from small phones to wide desktops.
- 🔗 **Deep-linkable anchors** — every poem, section, and the feedback form has a unique URL hash, so you can share a direct link to any piece.
- ✉️ **Feedback form** — a no-backend form that opens the reader's email client, pre-filled and addressed to the author.
- ♿ **Accessibility touches** — ARIA labels, keyboard support (Escape to close the mobile menu), `prefers-reduced-motion` support, and semantic HTML.
